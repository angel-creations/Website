# Angel Creations — Inner-Page Design System

## Purpose

This is a small experience framework for the seven original Angel slider destinations. It is not a replacement design system and must not introduce a parallel visual identity.

## Locked Angel DNA

- black/dark immersive field
- original slider-derived media language
- source-slide number and caption continuity
- existing logo, vertical Menu and Header
- warm restrained accent
- thin rules as anchors and progression marks
- existing type family and controlled scale
- asymmetric but precise spatial rhythm
- normal browser scroll

## Shared primitives

| Primitive | Purpose | Guardrail |
|---|---|---|
| **Experience Entry** | Carry a source-slide visual into a route title, controlled caption and immediate entry link. | No centered generic hero, no blocking intro. |
| **Experience Statement** | Give the medium a concise reason to matter. | Comfortable reading measure; no giant editorial headline. |
| **Experience Map** | Show a route-specific linear/spatial progression inside a reactive existing-media field. | Selection shifts the crop, rule planes and supporting explanation; no radial diagram, dashboard or fabricated image. |
| **Application Explorer** | Let a visitor choose a source-approved application and reveal its supporting copy. | Selection changes its existing-media composition and panel; all items remain semantic/static; no card grid. |
| **Experience Work** | Turn “Show the work” into source-integrated evidence. | Exact archive title/description/media/URL only. |
| **Capability Relationship** | Reveal the disciplines behind the experience. | Curated subset, never an indiscriminate taxonomy dump. |
| **Journey Navigation** | Continue to Home, previous, current position and next homepage experience. | Four-part Angel route rail; current item exposes `01–07 / 07`; a vertical sequence on mobile. |
| **Contextual CTA** | Turn exploration into a route-specific conversation. | Text link treatment, never a giant generic Contact button. |

## Motion vocabulary

| Moment | Duration | Behaviour |
|---|---:|---|
| Entry | 400–700ms | Media opacity plus a small directional copy transform; the route is immediately usable. |
| Map/app selection | 150–300ms | Immediate active-line and supporting-copy feedback. |
| Content reveal | 300–600ms | Controlled sequential reveal only when it clarifies order. |
| Page transition | 500–800ms maximum | Existing slide continuity, never a blocking theatrical loader. |

Reduced motion removes nonessential transition, video motion and transform choreography while retaining map/application content and navigation.

## Immersive choreography

- Existing source-slide media remains the visual source; interactive crops, warm rules and compositional planes create depth without invented work imagery.
- Supported browsers receive non-blocking CSS view-timeline chapter and explorer reveals. Unsupported browsers retain the complete static composition and normal scroll.
- Map/application selection is a meaningful control: it changes its active supporting panel, selected line and media composition. A visible “Continue” control moves to the next stage without trapping the visitor.
- No animation blocks reading, takes over scroll, or relies on canvas/WebGL. The full sequence remains reachable by ordinary scroll, keyboard and touch.

## Responsive behaviour

| Range | Composition rule |
|---|---|
| **320–479px compact phones** | One deliberate vertical reading path; full-width map/application controls; 44px minimum interactive targets; hero uses safe-area padding and a reduced floor height. |
| **480–699px larger phones** | Two-up map indices where space permits; applications stay vertical; media scales by viewport width, not a desktop crop. |
| **700–1023px tablets** | Separate two-axis composition: wider media, three-column map indices, two-by-two journey rail and rebalanced work media/copy. |
| **1024–1439px desktops** | Four-up control index where it supports scanning, asymmetric chapter rhythm and restrained line length. |
| **1440–2199px large displays** | Atmosphere grows through media field and gutters while the reading measure stays controlled. |
| **2200px+ ultra-wide** | Inner content remains capped and centred; media expands without turning copy into a billboard. |
| **Short landscape** | Entry height, media field and copy padding reduce to avoid a large empty cinematic viewport. |

All ranges retain numbers, route sequence, source media, normal scroll, keyboard operation and touch targets. Safe-area insets are applied on touch devices. Reduced motion removes decorative movement without replacing the composition with a different information architecture.

## Accessibility and SEO

- semantic H1/H2/H3, native buttons/links and logical DOM order
- map controls expose selected state and keyboard operation
- focus states use Angel’s existing high-contrast rule treatment
- noninteractive static fallback carries all meaningful long-form copy, Work links and navigation
- no essential information is canvas-only, media-only or interaction-only

## Prohibited patterns

No card grids, bento, glass, gradients, generic hero/benefit/CTA template, testimonial block, stat strip, radial diagram, floating 3D object, scroll hijack, animation framework or new navigation system.
