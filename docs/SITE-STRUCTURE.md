# Site Structure

## Source platform

- WordPress, using the custom `fleava` theme with Elementor assets; Yoast SEO Premium reports itself in source.
- The primary site wrapper is a bespoke full-screen video/slideshow design. `/metaverse/` is a separate Unity WebGL document, not the WordPress shell.
- The global header links to Home, Metaverse, 360 video; its overlay menu links to About Us, Works, Contact. The overlay footer includes the captured contact/legal links.
